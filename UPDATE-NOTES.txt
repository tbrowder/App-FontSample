App::FontSample publication cleanup

This update implements the four publication observations:

1. Each sample page identifies its purpose, font(s), and relevant point size.
2. Comparison no longer defaults to the same Hamburgefonts string used by
   the compact collection layout.
3. The duplicate public "waterfall" layout name is removed. Specimen retains
   its size-waterfall section.
4. Pangrams are labeled with language name and two-letter code. The current
   built-in pangram is "English (en)".

New/updated files include renderer code, API/CLI/config handling, docs,
current-capabilities example, and tests.

DELETE-FILES.txt lists three obsolete waterfall example/test files that
should be removed from the existing source tree.

The Raku tests were not run in this environment.
